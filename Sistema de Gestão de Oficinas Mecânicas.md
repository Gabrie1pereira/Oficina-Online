Projeto desenvolvido com o objetivo de facilitar a gestão de oficinas mecânicas por meio de uma solução web responsiva. Com ele, oficinas podem controlar desde o cadastro de clientes e veículos até o andamento dos serviços e o gerenciamento de estoque de peças.



## Funcionalidades

- Cadastro de clientes, veículos e colaboradores
- Agendamento de serviços com status de progresso
- Emissão de orçamentos e ordens de serviço
- Notificações automáticas (promoções, revisões)
- Pagamento via Pix e cartão
- Controle de estoque de peças em tempo real
- Relatórios financeiros e operacionais (KPIs, NPS)
- Acesso remoto via web e mobile
- Perfis de acesso: Cliente, Oficina, Fabricante, Administrador



## Tecnologias Utilizadas

- **Backend:** Python, Node.js
- **Frontend:** HTML, CSS, JavaScript
- **Banco de Dados:** MySQL
- **BI e Relatórios:** Power BI
- **Outros:** Git, APIs REST, Azure, WordPress
